## 旧稿为何失败

旧稿把后台验收表直接变成正文目录：每章都有“建立直觉、运行机制、失败树、工程调试、自测、权威来源”。学生没有正在完成的任务，术语也不是为解决眼前问题而出现。自动脚本进一步给所有章节填入相同句式，并固定填写 87 分，造成结构通过、教学失败。

## 金样章写法

第 1 章只完成一个任务：让 Claude Code 在一个已有项目里找到并修复登录错误提示，然后用测试和 diff 检查结果。学生在任务中依次遇到四个问题：它怎样知道项目内容、为什么能改文件和运行命令、为什么有时停下来询问权限、修改后怎样判断没有改坏。

正文不出现制作术语。每个命令前说明目的，命令后说明可见结果。每个专业词都在第一次出现处用当前案例解释。图解分别回答“它能看到什么”“一次任务怎样循环”“权限为什么会打断”“diff 和测试各检查什么”。

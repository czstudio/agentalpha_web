01

QUICK ANSWER

### 💡 简要回答

Timeline：9.3 一面 → 9.9 二面 → 9.16 三面 → 9.19 HR 面 → 9.23 OC，9.26 正式 offer。三年纯 Java 后端，去年开始蹭 LLM 的活，业余搓了两个 Agent 项目（多 Agent 协作的代码审查工具 + RAG 客服机器人），简历就往这个方向改了。

三轮面试各有侧重：一面确认后端底子和项目真实性；二面把后端题全部换成 Agent 皮肤，架构图、状态隔离、幂等、调度器，一个不落；三面聊方向判断和团队管理，先定评测集和 trace 体系那句是全场最对的一句话。

  

02

DEEP DIVE

### 📝 详细解析

一面（60min）：平台工程向，偏基础

1\. 自我介绍，直接问了句"你后端做的好好的，为什么转Agent开发"（这个问题三面又问了一遍，感觉是必考题）；

2\. 后端转过来，你觉得哪些能力是能复用的，哪些是要重学的（我说了高并发、异步、状态管理这些能复用，prompt工程和评测体系是重学的，他点头了）；

3\. 你那个代码审查Agent，Memory是怎么管的？多轮对话上下文越来越长怎么办，截断策略是什么；

4\. 为什么用LangGraph不用直接手写一个循环调用？Graph范式跟ReAct比好在哪，什么场景反而该用ReAct；

5\. Agent调工具的异常处理：工具超时、返回格式不对、模型幻觉出不存在的工具名，分别怎么兜；

6\. RAG的切块策略讲下，遇到代码块、表格、跨页引用怎么处理；embedding模型怎么选的，有没有fine-tune过；

7\. 评测怎么做的，数据集哪来的，准确率怎么定义的，上线前有没有灰度；

8\. 手撕：合并区间，秒了，然后加问"如果区间流是无限流式来的怎么办"（答了堆+增量合并的思路）。

一面感觉就是确认两件事：后端底子是不是真的，Agent项目是不是自己写的。

二面（75min）：leader面，强度拉满

1\. 无自我介绍，上来让画多Agent代码审查工具的架构图，画完指着图逐个组件问为什么；

2\. 多个Agent并发跑，状态怎么隔离？共享上下文会不会互相污染？LangGraph的checkpoint你怎么用的，存哪了；

3\. 上下文爆窗口遇到过吗？说了滑动窗口+摘要压缩，追问摘要丢了关键信息怎么办，怎么权衡压缩率；

4\. Sandbox怎么设计的，Agent生成的代码你敢直接执行吗？容器隔离、资源限制、网络白名单分别怎么做的；

5\. 工具调用的幂等性怎么保证——Agent重试一个"创建PR"的工具，会不会创建两个PR？（这题明显是后端经验题换了身皮，答了请求ID+去重表，他追问了分布式场景下的实现）；

6\. GraphRAG和传统RAG的区别，知识库增量更新时graph怎么更新，实体冲突怎么合并；

7\. 流式输出的工程细节：SSE怎么做的，断线重连后怎么续传，背压问题考虑过吗（幸好后端老本行干过这块）；

8\. 场景题：设计一个能操作外卖商家后台的经营助手Agent，商家说"最近生意不好帮我看看"，从意图识别到调数据接口到生成建议，完整链路设计一下。中途加需求："如果Agent误判了意图改了商品价格怎么办"——答了高危操作人工确认+操作可逆+审计日志；

9\. 手撕：实现一个带并发限制的异步任务调度器（说考的是真后端能力+Agent框架里调度器的理解）。

工具幂等、状态隔离、异步调度，全是后端题的 Agent 皮肤。

三面（40min）：总监面

1\. 自我介绍，又问了一遍为什么转方向，这次追问"你怎么看Agent这个方向两年后的样子，会不会是泡沫"；

2\. 平时怎么跟进LLM领域进展的，论文、开源项目、还是公众号（老实说三个都看，讲了个最近复现失败的经历，他反而聊开了）；

3\. Agent输出不稳定怎么排查，从prompt、采样参数、工具返回值、评测集四个层面聊的；

4\. 如果让你带一个三人小组从零做Agent平台，你第一个月干什么（我说了先定评测集和trace体系，没有观测就没有迭代，他重复了一遍这句话，感觉答到点子上了）；

5\. 反问：问了组里Agent落地的实际场景和容错成本。

HR面（25min）

和之前差不多：手里offer、期望薪资、能不能提前实习。多了个"转型期薪资预期怎么看的"，如实说了平薪可接受，主要看方向。

SUMMARY

### 🎯 面试总结

后端转Agent，面试官默认你的后端是真的，所以八股不硬考，但会换着花样融进Agent题里——工具幂等、状态隔离、异步调度，全是后端题的Agent皮肤；

"为什么转方向"三轮都问了，答案要经得起追问，说"感兴趣"是不够的，得有具体的项目和时间线证明你早就在转了；

评测、观测、兜底这三件套被问的频率远超prompt技巧，感觉大厂要的是"能把Agent当系统做"的人，不是"会调prompt"的人；

自己搓的项目比跟教程做的值钱太多，二面那张架构图如果画不出来，大概率就挂了。

挑一个和今天最相关的模块，看看具体教什么、动手做什么、怎么验收：

阶段 9｜Agentic RL（1–1.5 周）

**学什么：**把「搜索/工具调用」建模成 RL 环境中的动作；交错推理加多轮搜索的训练流程；奖励函数设计与 PPO、GRPO、Reinforce 的选型对比；训练稳定性技巧（retrieved token masking、防止模型走捷径、动态采样与难度过滤、训练数据配比）；veRL、EasyR1、Search-R1 三个框架的技术路线与递进关系。

**动手做什么：**复现 Search-R1，训练一个 3B–7B 的小模型，让它在「思考→触发搜索→整合→回答」的结构里学会何时发起搜索。

**怎么验收：**报告必须包含训练前后模型检索次数与搜索触发位置分布的变化、答案质量（F1/EM）与「引用有效率」的提升、以及 1 到 2 个失败样本的归因和改进思路，比如把多 Agent 代码审查工具的架构图完整画出来，逐个组件回答为什么这么设计，再补上 checkpoint 存哪、工具调用幂等怎么做、上下文爆了怎么处理这三问。

**学员案例**（来自社区公开资料）：字节 Seed、腾讯、京东 TGT、蚂蚁 PLAN-A、华为天才少年等录用结果；ICLR、KDD、ICML、NeurIPS、EMNLP、AAAI 等论文录用；USC、杜克、港科大等博士录取。

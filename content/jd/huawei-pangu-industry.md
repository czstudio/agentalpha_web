## 这条 JD 在招什么人

把大模型装进行业客户环境里跑起来的工程师。华为盘古的路线是行业模型：气象、矿山、政务、制造这些场景，交付形态以私有化为主。JD 里出现「行业解决方案」「私有化部署」「训推一体」「昇腾」，说明要的是工程与系统设计能力：客户环境里资源受限、网络隔离、数据不能出门，怎么把模型服务、知识库、Agent 应用整套搬进去并稳定运行，这是重心。

## 业务场景推测

大概率是某个行业线的模型应用交付：政企知识库问答、生产场景的智能辅助、或气象/矿山等垂直场景的模型服务化（置信度：中高）。也可能包含昇腾生态的适配与优化工作。行业项目的节奏是 POC、投标、驻场、验收，和互联网的迭代节奏差别大。

## 硬技能：必须会什么

- 私有化部署：自建与调 API 的边界、资源评估、离线环境运维（[私有化](/interview/qa/llm-private-deployment)）
- 推理优化基础：量化（INT8/INT4）、KV Cache 量化、吞吐与延迟的权衡
- 企业 RAG：行业知识库的坑、权限进检索（[ACL](/interview/qa/rag-acl-permissions)）
- 数据合规：行业数据能不能训、脱敏与授权边界（[合规](/interview/qa/training-data-compliance)）
- 系统设计：整套方案的架构拆解，从模型服务到应用到监控的完整图纸
- Agent 基础：工具调用、任务编排，行业场景里多是流程固定型任务

## 加分项：什么能拉开差距

- 有行业交付经历（政务、能源、金融任一）：能讲清验收标准和踩过的坑
- 昇腾/国产生态实操：MindSpore、CANN 任意一项用过
- 系统设计表达训练过：白板画完整架构，答得出每个组件的备选方案
- 既懂算法又懂网络、存储、虚拟化的复合背景

## JD 没写但面试会问

- 私有化和调 API 怎么选：客户预算、数据敏感度、效果要求的三角权衡（高频）
- 一套行业大模型方案的系统设计：现场画架构（华为面经高频）
- 客户机房只有有限的卡，模型怎么部署、并发怎么估
- 行业数据合规红线怎么把握
- POC 效果好但上线效果掉，怎么排查

## 简历怎么改

- 行业项目按「客户约束-方案-验收结果」结构写，突出约束下的取舍
- 系统设计能力单独举证：画过什么架构、经过什么评审
- 国产生态经验（昇腾、鸿蒙、信创）显式写出，这是这个方向的相关性信号
- 别只写「参与了」：写清你负责的模块和它出过什么问题

## 项目建议

- 私有化 RAG 方案设计：含资源估算、量化选型、权限设计、监控，输出完整方案文档

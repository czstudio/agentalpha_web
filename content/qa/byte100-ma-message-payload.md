## 先这样答

系统必须按信息类型分层。关键状态使用结构化数据传递。结构化数据要求字段明确。接收方可以直接校验这些字段。这种方式能保证核心信息无损。叙事性上下文使用自然语言传递。自然语言保留了表达的灵活性。纯自然语言传递会在多轮对话中逐轮失真。纯结构化传递会丢失原始语境。

控制信息损失需要执行传递契约化。开发者提前定义各个 Agent 之间的必传字段。发送方必须按照契约输出数据。接收方拿到数据后主动确认关键字段。

跨 Agent 传递结论要求更加严格。发送方传递结论时必须附带信息来源。发送方还要给出该结论的置信度。接收方根据置信度和来源评估信息可靠性。按信息类型分层与契约机制能有效控制信息损失。

## 面试官会怎么追问

- **「接收方确认关键字段时发现缺失怎么处理？」**
接收方根据传递契约拦截这条信息。接收方直接向发送方报错。报错信息包含缺失的具体字段名称。接收方要求发送方重新提供必传字段。

- **「跨 Agent 传递结论为什么必须带来源与置信度？」**
纯自然语言在多 Agent 间传递会逐轮失真。来源标记能让下游 Agent 追溯原始语境。置信度帮助接收方评估结论的可靠程度。接收方依据置信度决定采纳策略。

- **「纯结构化传递具体会丢失什么语境？」**
结构化数据只保留预定义的关键状态。它会过滤掉灵活的叙事性上下文。接收方失去这些自然语言背景容易产生误判。自然语言能补充结构化字段无法覆盖的背景细节。

## 回答的坑

答题时认为只能在自然语言和结构化数据中二选一，没有提出按信息类型分层处理。
忽略跨 Agent 传递的逐轮失真现象，忘记提及传递契约化与结论附带置信度机制。

## 先这样答

结论是：按职能拆角色，按任务看板共享状态，按分层条件判断完成。广告投放可以拆成三个 Agent。洞察 Agent 分析受众与素材。方案 Agent 输出投放策略。审核 Agent 做合规与预算校验。这样划分让每个 Agent 都有清楚的工作边界，也让审核保持独立。

共享状态走集中存储。可以用任务看板记录各 Agent 的产出与进度。后续 Agent 从看板读取需要的信息。各 Agent 不点对点传状态。完成条件分两层。单 Agent 先满足自己的交付物定义。整体任务再由编排方判定是否完成。审核 Agent 要独立于方案 Agent，不能既当选手又当裁判。

回答这道题时，我会先说明划分原则，再说明状态位置，最后说明完成判定。角色划分看职能，不按 Agent 之间的调用关系划分。状态共享看任务进展，不让信息散落在点对点传递里。完成判定看交付物，不把某一个 Agent 的完成当成整体完成。

## 面试官会怎么追问

- **「为什么不让方案 Agent 自己做审核？」** 审核需要独立于方案。方案 Agent 负责出策略，审核 Agent 负责合规与预算校验。让同一个 Agent 既当选手又当裁判，违背审核独立的要求。

- **「为什么要用集中任务看板，不能让 Agent 直接互相传消息？」** 任务看板集中记录各 Agent 的产出与进度。共享状态放在集中存储，不做点对点传递。编排方可以依据同一份任务状态判断进展。

- **「单个 Agent 说自己完成了，整体任务就算完成吗？」** 不能直接这样判断。单 Agent 需要先满足自己的交付物定义。整体完成还要由编排方判定。

## 回答的坑

- 把洞察、方案、审核混在一个 Agent 里，或让方案 Agent 同时承担审核，都会破坏按职能划分和审核独立。

- 只看某个 Agent 是否完成，不定义各自交付物并交给编排方判断整体完成，就会把局部完成误当整体完成。

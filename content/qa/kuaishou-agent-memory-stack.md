## 先这样答
我会把 Agent 的长期记忆做成分层方案，而不是只放一个向量库。向量库保存历史对话的 embedding，供后续检索。实体记忆从对话中抽取实体和关系，再组织成知识图谱。摘要记忆则定期压缩历史内容，让记忆保留更紧凑的表达。

检索时，我会把时间衰减因子和相关性得分放在一起排序。相关性反映当前问题与记忆内容的匹配程度，时间衰减则让近期记忆得到相应考虑。这样，向量检索、实体关系和历史摘要各自承担不同作用，检索结果也不只由单一的向量相似度决定。

面试里我会先讲清这四层，再说明排序方式。重点不是把每种记忆讲成互不相关的功能，而是解释它们如何共同回答当前问题。只用向量库描述长期记忆，会漏掉实体关系和定期摘要这两层，也没有交代时间因素如何参与检索排序。

## 面试官会怎么追问
- **「为什么不直接用向量库存所有历史对话？」** 向量库可以保存历史对话的 embedding，但这套方案不只依靠向量检索。实体记忆会抽取实体和关系，摘要记忆会定期压缩历史。回答时应强调分层，不把长期记忆等同于单一向量库。
- **「实体记忆和摘要记忆分别解决什么问题？」** 实体记忆把实体及其关系组织成知识图谱。摘要记忆定期压缩历史内容。两者在方案里承担不同的记忆组织方式，不应混成同一层。
- **「检索时怎么决定哪些记忆排在前面？」** 我会把相关性得分与时间衰减因子联合排序。相关性用于衡量记忆和当前检索的关联，时间衰减让时间因素也进入排序。

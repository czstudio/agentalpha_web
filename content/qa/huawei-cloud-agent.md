## 先这样答

AI Agent 在华为云场景下，主要可以做三类事情：运维助手、客服与交付、行业场景服务。华为云面向企业客户，回答时还要强调可信、可审计和支持私有化。

第一类是运维助手。Agent 可以聚合多源日志和监控数据，围绕告警做根因分析。它还可以根据分析结果生成变更方案，并提前检查方案风险。这样，Agent 不只回答告警是什么，还能继续分析原因，给出处理方案。

第二类是客服与交付。它可以回答华为云工单问题，也可以作为方案配置助手，协助客户完成配置。第三类是行业场景服务。华为可以把盘古行业模型和 Agent 编排服务开放给政企客户，让客户在自己的行业场景中使用。回答这道题时，要把这些能力和华为云的 toB 属性放在一起说。企业客户会关注结果是否可信，过程能否审计，部署是否支持私有化。

## 面试官会怎么追问

- **「运维 Agent 和普通问答机器人有什么区别？」** 普通问答机器人主要根据已有内容返回答案。运维 Agent 需要聚合多源日志和监控数据，再进行告警根因分析。它还可以生成变更方案，并做风险预检，所以处理对象不只是文本问题。

- **「为什么华为云场景要强调可信、审计和私有化？」** 华为云面向企业客户，企业使用 Agent 时会关注答案是否可信。企业还需要了解 Agent 做过什么、依据什么结果行动，因此要关注审计。部分客户也会关注部署方式，私有化是回答时需要带出的差异点。

- **「盘古行业模型和 Agent 编排服务可以怎么结合？」** 盘古行业模型提供行业场景中的模型能力。Agent 编排服务负责组织 Agent 的处理过程。华为可以把这两类能力开放给政企客户，让客户用于各自的行业场景。

## 回答的坑

- 只说 Agent 能聊天和回答问题，没有讲告警根因分析、变更方案生成与风险预检，就没有答到运维助手的关键能力。

- 只罗列技术能力，没有结合华为云的 toB 属性说明可信、审计和私有化，答案会缺少场景判断。

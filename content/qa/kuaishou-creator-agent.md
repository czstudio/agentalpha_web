## 先这样答

Agent 可以围绕选题、脚本、标题封面、发布策略和数据复盘五个环节辅助短视频创作者。它先分析历史爆款的特征，再结合趋势给出选题建议。这样能让创作者先明确内容方向，再进入生产环节。

在脚本环节，Agent 可以按照 hook、正文、CTA 的结构生成和修改脚本。它也可以结合目标时长优化内容安排。标题和封面环节可以生成多个候选方案，再用 CTR 预估进行排序，帮助创作者选择更合适的组合。

发布时，Agent 可以根据受众的活跃时间给出发布时间建议。发布后，它分析完播和互动数据，并对标同类内容，指出可以改进的地方。技术上，需要对接平台数据 API 和内容分析工具。这样，创作者能根据数据调整后续选题、脚本和发布安排。

## 面试官会怎么追问

- **「你会怎样设计 Agent 的任务流程？」** 先让 Agent 获取历史内容、趋势和受众数据。再按五个环节依次生成建议。最后结合发布后的完播和互动数据，输出下一轮调整意见。

- **「为什么标题和封面要生成多个候选，而不是直接生成一个？」** 单个方案很难覆盖不同表达方向。多个候选可以提供比较空间。Agent 再结合 CTR 预估排序，帮助创作者选择方案。

- **「数据复盘时，你会重点看哪些指标？」** 重点看完播和互动。Agent 需要把这些数据与同类内容对标。然后指出内容中需要调整的部分，并给出后续建议。

## 回答的坑

- 不要只讲生成脚本，还要覆盖选题、标题封面、发布时间和数据复盘五个环节。
- 不要把 CTR 预估说成真实结果，它只能用于候选方案排序。

## 先这样答

A2A 不是 MCP 的竞品。MCP 解决 Agent 向下连工具的问题，A2A 解决 Agent 向外协作的问题。两套协议面向的对象不同，也负责不同方向的连接。不能只因为它们都是协议，就认为它们在争同一个位置。面试时先给出这个结论，再分别说明它们连接谁。不要只说“两者可以共存”，却不说清为什么能共存。

具体的共存方式是：每个 Agent 用 MCP 管自己的工具层。Agent 需要把子任务交给其他 Agent 时，Agent 之间用 A2A 委派子任务。前者处理 Agent 与自身工具的关系，后者处理 Agent 之间的协作。一个 Agent 可以同时处在这两种关系里，因此不需要在 MCP 和 A2A 之间二选一。回答时把“每个 Agent”和“Agent 之间”说清楚，分工就明确了。

这道题来自快手 Agent 开发一面。有人答“A2A 是 MCP 的竞品”，面试官当场反问：“两个协议面向的对象都不一样。”这个反问点出了答题关键：先看协议面向的对象，再谈两者的关系。完整回答可以按三个步骤讲：先否定竞品判断，再说各自的连接方向，最后说明 MCP 管工具层、A2A 负责 Agent 间的子任务委派。这样既答了“是不是竞品”，也答了“怎么共存”。

## 面试官会怎么追问

- **「你为什么说它们不是竞品？」** 因为两者面向的对象不同。MCP 解决 Agent 向下连工具，A2A 解决 Agent 向外协作。判断是否竞争，先看它们是不是在解决同一个方向的问题；这里不是。
- **「一个 Agent 同时用两套协议，你怎么讲清分工？」** 我会按连接对象来讲。这个 Agent 用 MCP 管自己的工具层。它要向其他 Agent 委派子任务时，Agent 之间用 A2A。
- **「如果我让你只用一句话说共存方式呢？」** 每个 Agent 用 MCP 管自己的工具层，Agent 之间用 A2A 委派子任务。这句话分别交代了两套协议面向谁。它也说明共存不是二选一。

## 回答的坑

- 把 A2A 答成 MCP 的竞品，却说不清两套协议各自面向什么对象。
- 只说“两者能共存”，却不说明 MCP 管工具层、A2A 管 Agent 之间的子任务委派。

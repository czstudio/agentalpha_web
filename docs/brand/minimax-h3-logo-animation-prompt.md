# AgentAlpha Logo 动画｜MiniMax H3 制作提示

## 输入

- 首帧参考：`public/logo-light.png`
- 时长：6 秒
- 画幅：16:9
- 背景：深海军蓝 `#071A2E`
- 镜头：固定机位，正面平视，不推拉、不旋转

## 主提示词

严格保持输入 Logo 的字形、猫头轮廓、比例和品牌拼写，不重新设计 Logo。画面从纯深海军蓝开始，一条细而锐利的钴蓝信号线从左向右划过，像一次稳定的智能体任务脉冲。信号线经过之处，AgentAlpha Logo 由精密的工程网格和少量蓝色粒子逐段显现：先勾勒猫头轮廓，再显现完整英文标识。粒子只服务于轮廓生成，不向四周爆炸。Logo 完整出现后，信号线在右侧形成三个短暂发光的节点，节点依次点亮，随后光效迅速收敛，留下清晰、平整、完整的静态 Logo。整体像高端科技品牌的片头识别动画，克制、精确、有力量，黑蓝与钴蓝配色，轻微体积光，真实运动模糊，结尾停留 1.5 秒，便于网页无缝衔接。

## 负面约束

不要改变任何字母，不要生成额外文字、标语、水印或界面元素；不要故障乱码、霓虹赛博朋克、玻璃拟态、金属 3D 字、火焰、闪电、宇宙星空、镜头旋转、过度粒子爆炸；不要让 Logo 弯曲、融化、抖动或被遮挡；结尾必须完整还原输入 Logo。

## 网页衔接要求

- 第一帧与页面品牌舞台背景同色。
- 最后一帧必须是稳定完整的 Logo，不残留粒子。
- 导出 H.264 MP4 与无音轨 WebM；网页默认静音、仅播放一次。
- 在真实 H3 成片验收前，网站继续使用同一叙事的原生矢量动效，不以其他模型结果冒充 H3。

# Agent 岗面试宝典：60 篇专题文章选题

来源：AgentAlpha 飞书文档《Agent 岗面试宝典 v3》。每章先选 5 篇，后续按文章金标准逐篇写入站点；题目是原创编辑标题，底层考点来自飞书真题，不直接搬运题库答案。

## 第 1 章 · RAG

1. 《RAG 为什么不是“向量库 + 提示词”？一条检索链路到底经过什么》——全链路、数据准备、召回、组装、生成
2. 《Embedding 到底把什么变成了向量？相似度高就一定相关吗》——表示、距离、模型选择、领域适配
3. 《RAG 分块不是把文章切成  Markdown：Chunk 大小、重叠和语义边界怎么定》——分块、父子块、结构化文档
4. 《向量数据库里到底存什么？从索引、过滤到冷热分层讲清楚》——存储结构、索引、选型、扩展
5. 《为什么检索到了正确文档，答案还是错？从召回到重排再到评测》——混合检索、Rerank、Recall、Faithfulness

## 第 2 章 · LLM 基础

1. 《Attention 不是“注意力”：一行公式如何变成上下文理解》——QKV、复杂度、长文本
2. 《Transformer 为什么能替代 RNN？从并行训练到位置编码》——架构、残差、归一化、位置表示
3. 《MoE 为什么能少算一点还变大？路由、负载均衡与专家塌缩》——稀疏激活、Router、容量因子
4. 《KV Cache 到底缓存了什么？为什么长对话越聊越贵》——Prefill、Decode、显存、Paged Attention
5. 《大模型推理优化不是只换量化：吞吐、延迟和显存怎么一起看》——量化、批处理、投机解码、服务指标

## 第 3 章 · LLM 训练

1. 《SFT 不是把答案背下来：一条训练样本如何改变模型行为》——数据格式、损失、质量控制
2. 《RLHF 为什么要奖励模型？从偏好数据到 PPO 的完整链路》——奖励建模、KL、策略更新
3. 《DPO 和 PPO 到底差在哪？什么时候不需要单独训练奖励模型》——目标函数、稳定性、数据要求
4. 《训练 loss 降了，模型为什么没变聪明？训练稳定性排查清单》——过拟合、数据污染、评测错位
5. 《预训练数据不是越多越好：清洗、去重和数据配比如何影响能力》——数据工程、质量、混合策略

## 第 4 章 · Agent 架构

1. 《Agent 已经会 ReAct，为什么还要做 Agentic RL？》——已有专题，后续继续补充配图与实战
2. 《记忆系统不是聊天记录：短期记忆、长期记忆和压缩怎么分工》——上下文、摘要、检索记忆
3. 《规划与反思什么时候有用，什么时候只是让 Agent 多说废话》——计划、执行、反思、停止条件
4. 《Agent 安全不是加一句提示词：权限、工具和数据边界怎么设计》——越权、注入、审批、审计
5. 《Agent 上线后怎么定位问题？从 trace 到可观测性和回放》——日志、指标、链路、评测

## 第 5 章 · 多智能体

1. 《为什么一个 Agent 做不完的事，要拆成多个 Agent？》——任务边界、协作收益、额外成本
2. 《多 Agent 不是群聊：角色分工、消息协议和状态同步怎么做》——协作协议、共享状态
3. 《多 Agent 互相甩锅怎么办？从监督者到仲裁器设计》——冲突、投票、裁决、失败恢复
4. 《多 Agent 系统为什么越加人越慢？并发、上下文和预算控制》——拓扑、并发、成本、尾延迟
5. 《如何评测多 Agent 协作？不能只看最终答案》——个体贡献、协作效率、稳定性、安全

## 第 6 章 · 多模态

1. 《多模态模型不是“给图片加一个输入框”：图像如何进入 Transformer》——视觉编码器、投影、融合
2. 《图片问答答非所问，问题可能不在模型而在视觉切片》——分辨率、切片、OCR、布局
3. 《文档理解为什么要保留版面？从 OCR 到表格和图表解析》——结构恢复、坐标、跨页
4. 《多模态 RAG 怎么检索图片、表格和文字》——统一表示、跨模态召回、引用
5. 《视频 Agent 如何处理百万级帧？采样、时间定位和证据回放》——关键帧、时间轴、长视频

## 第 7 章 · 评测

1. 《Agent 评测不能只看成功率：任务、过程、成本和安全要分开》——指标分层
2. 《RAG 答案看着对，怎么证明它真的有依据？》——Faithfulness、引用、归因
3. 《离线评测很好，线上却翻车：数据集、分布漂移和回归集》——评测集治理
4. 《大模型裁判也会错：LLM-as-a-Judge 的偏差与校准》——一致性、盲测、人审
5. 《一次 Agent 实验怎样才算可复现？环境、轨迹和版本都要锁住》——回放、随机性、证据链

## 第 8 章 · 工具调用

1. 《Function Calling 不是让模型“会调用函数”：参数、协议和验证》——Schema、解析、校验
2. 《工具调用失败后，Agent 应该重试、换工具还是停下来？》——错误分类、退避、熔断
3. 《MCP 解决了什么问题？工具协议标准化之后仍有哪些坑》——资源、工具、权限、版本
4. 《工具返回一大段 JSON，为什么 Agent 反而更容易做错》——观察压缩、字段设计、分页
5. 《如何给工具调用做权限控制和审计？》——最小权限、审批、审计日志、幂等

## 第 9 章 · 编程题

1. 《代码 Agent 为什么总要先读仓库，再开始写代码？》——已有专题，补充仓库索引和证据图
2. 《代码 Agent 说测试全绿，为什么我还是不敢合并？》——已有专题，补充验证矩阵
3. 《Code Agent 为什么不能直接给 root 权限？》——已有专题，补充沙箱威胁模型
4. 《代码 Agent 跑到一半挂了，怎么恢复而且不重复执行？》——已有专题，补充 exactly-once 状态机
5. 《从需求到补丁：一个可靠 Code Agent 的任务分解、修改和验收》——综合项目题

## 第 10 章 · 项目深挖

1. 《面试官让你从零设计企业知识库 Agent，先画哪张图》——架构、数据、权限、评测
2. 《你的 Agent 项目为什么要用 RAG？不用会怎样》——需求判断、替代方案、边界
3. 《项目里的指标是怎么来的？把 Demo 讲成可验证的工程系统》——基线、口径、实验
4. 《线上成本突然翻倍，Agent 项目从哪里开始降本》——模型、缓存、路由、工具预算
5. 《项目被追问“你做的和框架有什么区别”，怎样讲出自己的贡献》——决策、取舍、复盘

## 第 11 章 · 通用与软实力

1. 《不会的 Agent 面试题怎么答：先拆问题，再声明假设》——不装懂的结构化回答
2. 《项目讲不深，通常不是项目小而是证据链断了》——背景、动作、结果、复盘
3. 《面试官追问失败案例时，怎样讲得具体又不自毁》——责任边界、改进、学习
4. 《技术方案有争议怎么办？从不同意见到可验证实验》——沟通、决策、记录
5. 《Agent 工程师的学习路线怎么排：基础、项目、论文和面试如何互相喂养》——学习计划

## 第 12 章 · 五厂高频题

## 写作顺序

先完成第 1 章的 5 篇，作为 RAG 专题卷；每篇达到文章金标准并通过移动端排版检查后，再进入下一章。已有文章会按对应章节归档，不重复创建同题文章。

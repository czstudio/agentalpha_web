它怎么工作

一条记忆，从说出口到被遗忘

往下滑，跟着「我以后都喝低因咖啡」这句话走完一生。

01 你说了一句话

不是每句话都值得记。MemSync 先判断：这是偏好、事实，还是闲聊？

02 写入前先过闸

一个专门训练过的小模型决定记不记。密码、证件号这类东西，拦在门外。

03 分层存放

工作记忆、短期、中期、长期四层。晋升必须早于挤出，重要的不会被新消息冲掉。

04 需要时被想起

向量检索加关键词检索双路召回，再用重排模型挑出最相关的几条。

05 慢慢变淡

很久没用到的记忆权重逐步衰减，给新信息让路。

06 改口与遗忘

你改主意了？旧版本留在版本链里，还查得到；你要删？打上墓碑，再也查不到。

07 对话太长就压缩

旧对话压缩成摘要，摘要本身也记着出处，随时能追回原文。

08 让 Agent 安全地用

代码智能体在沙箱里调用记忆、学习新技能，改动先过统计闸门再上线。

打开记忆，AI 终于记得住你的要求

同一批 81 道题、同一个本地 7B 模型：关掉记忆只答对 17 道，打开记忆答对 45 道。统计检验 p=0.0001，不是运气。

0.230.56

在超长对话里翻旧账

LoCoMo 超长对话基准：只靠向量检索，前 5 条里找到正确记忆的比例是 23%；加上混合检索和重排，涨到 56%。中文 LongMemEval 上做到 95%。

58%94%

GRPO 把 1.5B 小模型练成尖子生

同一个基座、同样的预算，SFT、DPO、GRPO 三种方法正面比。500 道测试题的全对率，GRPO 从 57.6% 拉到 94.0%，三者里最高。

64%86%

学会判断什么该记、什么不该记

规则写死的门控只判对 64.3%，训练出的决策模型做到 86.1%。误把机密信息写进记忆的次数，从 18 次降到 7 次。

−64%

让第一个字更快出现

600 多条真实提示词共享系统前缀，开启前缀缓存后，首字延迟中位数从 36.4ms 降到 13.0ms。另外 FP8 量化和 FP16 质量差别测不出来，AWQ 省下 31% 显存。

1.66×

亲手写一个 Triton 算子

把残差加和 RMSNorm 融合成一个内核，比 torch.compile 快 1.66 倍，输出逐元素一致，46 项测试全绿。

奖励、成功率、损失、步耗时四张子图。你会看懂每一个拐点为什么出现，还会做 7 组奖励设计对照，知道哪种奖励真正管用。

三种范式正面比过

「你遇到过什么坑？」

最加分的一题

常见问题

我只会 Python，跟得上吗？

会 Python、了解 PyTorch 的基本用法就能开始。大模型相关的知识，项目里边做边补，每个模块开头都有热身说明。

必须有一张 4090 吗？

页面上的数字都是在单张 RTX 4090 上测的。没有卡也能学：检索、评测、数据处理这些模块不吃显存；训练部分可以租云 GPU 跑通同款流程。

以前的 RAG、多 Agent 那些项目还学吗？

都在 MemSync 里面：检索是它的记忆召回，多 Agent 和深度研究是它的科研工作台，强化学习是它的决策模型。按能力单独看的旧版模块页，放在页面底部的「全部项目」里。

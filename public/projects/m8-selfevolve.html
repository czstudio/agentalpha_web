01

场景故事

让 Agent 变强有两条路：换更强的模型，或者让它从自己的经验里学

这个项目走第二条：把 Agent 解题的轨迹（trajectory）当作可进化的对象，哪条轨迹解决了问题、用了哪些策略，抽象出来、打个分，好的策略变异、交叉、池化总结，再注入下一代 Agent 的提示里。

框架是四阶段循环：Original 阶段 N 路并行跑出基线轨迹；Alternative 阶段从高分轨迹生成替代策略再验证；Crossover 阶段把互补策略两两交叉产生新组合；Summary 阶段做全轨迹池化总结沉淀成策略库。防劣化靠加权无放回采样和 LLM rerank，成本靠每代 instance×rollout 预算和 API 调用核算控制。

在 harness 配置自进化层，进化对象换成 harness 自己的配置（步数预算、观察截断、gist 压缩阈值、系统提示规则）：提案器提出配置编辑，评测器在演化集上实测增益，选择核按噪声地板 δ 和证伪账本裁决是否接受。Round20-21 用五个实验把这条链路实跑收口，见下节台账。

可迁移场景：客服话术策略优化、检索策略自动调优，以及任意可打分的 Agent 任务。

03

δ(n) 样本量公式：先算 n 再开跑

把「这个增益是真的还是抽样噪声」从事后争论变成事前计算

公式：δ(n) = 2√2 · √( p(1−p) / n )。z=2 对应约 95% 置信、√2 是两臂独立评估之差的方差因子；p 取基线通过率，n 是每臂题目数。开跑之前先算 δ：小于 δ 的增益一律判为噪声带内，不接受、不宣传。

实测校验：R64 以 n=300、p=0.10 代入得预测 0.0490，实跑测得 0.0430，相对偏差 12.2%（预注册判据 <20%，PASS）。R62（n=60）的 δ=0.109 解释了为什么 +5pp 量级的增益在小样本下不可判：噪声地板比效应还大。逐条推导与口径见教程 §4.3 与 experiments/round20/r62b_delta.json。

配套机制：选择核（思想来源于 google-research/rrsi，工程实现自研）按 δ 裁决接受与否，配合证伪账本（被否提案记录在案不再重提）、退火预算、泄漏预筛、成本双口径与结构新颖度，代码在 code/idea2paper_evolution/evolution/harness_evolve.py，49 项单测实跑通过。

04

系统架构

四阶段循环负责产出候选策略，选择核负责裁决：只有实测增益超过噪声地板 δ 且通过泄漏预筛的候选才会进入下一代。进化的对象是策略与配置而不是代码，这是与 AlphaEvolve 系代码进化的根本区别。

08

面试深挖预演

R62 四臂全零，这轮实验算失败吗？
算有效的空结果。四臂共享同一矩阵、同解码种子，增益全零说明 Qwen3-0.6B 底座上提示词编辑根本不起作用，这直接驱动了 R62b 的三项设计修正（换 1.5B 底座、budget 4→6、n 60→100）。空结果推动设计修正，比硬凑一个正结果有价值。
+5pp 为什么最后被判定为抽样噪声？
R62b 的 +5pp 在 n=100 上测得，当时 δ=0.0856，增益小于噪声地板。R64 按 δ(n) 公式把 n 扩到 300，增益缩到 +2.5pp（p=0.222），预注册的 PR-c 判据自动触发「如实记录为抽样噪声」。这是本仓第三次公开自纠，前后数字都保留。
泄漏预筛为什么重要？
自进化循环的评估器如果被「内部备忘」类文本污染，会把答案泄漏当真实增益接受。R63 故意注入带标定答案的变体：预筛按任务名与答案值 denylist 当场拦截，一次评测调用都没花（eval_spent=false）。这道防线与证伪账本一样，都是选择核的常设部件。
让 1.5B 自己提案自己，结果如何？
R65 验证了端到端循环可行性：4 条提案全部可解析，3 条被证伪、0 条被接受，全程 486 秒。结论如实写为「循环跑通但不赚」：RRSI 的设计前提是提案器强于策略，同模型提案偏离了这个前提，页面不把它包装成正向结果。
你的进化循环和强化学习是什么关系？
结构上同构：多路 rollout、打分、选择、更新等价于进化策略做策略搜索。区别在更新载体：进化改 prompt 与 harness 配置，RL 改模型参数；GRPO 的组内相对优势对应本项目的组内轨迹打分。轨迹数据层已被 MemSync Train 复用为训练样本来源，两条路线在数据层打通。
教程在哪里？
Harness 自进化万字详解（m8b 外传），源仓库路径 docs/tutorials/m8b-Harness自进化万字详解.md（本站未发布 docs/ 目录，只给路径）。正文教程为 docs/tutorials/m8-自进化万字详解.md。

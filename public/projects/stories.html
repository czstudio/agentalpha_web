PATH 01

求职上岸

从双非本科到四年老兵，共同点是：项目不再停在「能演示」，而是能讲清失败、边界与代价。

CASE 00 · 旗舰

阿周

南方某 211 计算机本科
大三下开始 · 全程约 3 个月小红书算法岗实习转正 45k×16（SSP 档）总包约 72W+

起点：上一段实习在小厂做前端，简历上看不到大模型或推荐算法的影子；机器学习只会写公式，调不通一个真实模型；LeetCode 只刷过几十道，手撕 medium 容易卡壳。他卡在简历关前面，连面试的池子都进不去。算法岗 HC 收缩、大厂校招泡池子排序，光靠学校牌子排不到前面。

路线选择：比起海投校招拼运气，他选了更稳的一条：先用一段日常实习把背景补齐，再用实习转正把 offer 从不确定变成已落袋。

  1. 第 1 个月 · 集中备战：算法八股（SVM、树模型、深度学习、Transformer、召回排序基础）+ LeetCode 200 道核心题与剑指 Offer + 一个能演示的推荐/大模型项目（多路召回、向量检索、粗排精排，加一段简单 RAG/Agent 链路）。
  2. 第 2–3 个月 · 日常实习：扎进小红书信息流推荐的真实业务：召回侧优化、用 A/B Test 验证特征、把用户反馈和线上指标（CTR/CVR/留存）做成复盘，不当 toy demo。
  3. 转正答辩：导师评语 + 转正答辩 + 业务方认可，拿 return offer：45k×16，SSP 档，签字费/期权/房补另算。
实习转正答辩 · 项目被追问什么
Q1数据从哪里来？召回效果怎么评估？

项目阶段就补齐了评测口径；实习里用 A/B Test 验证特征与线上指标挂钩，避免只报离线数字。

Q2线上出了问题怎么排查？失败了怎么恢复？

链路里保留可复盘的日志与指标监控，问题能追到具体环节；这也成为他答辩时讲得最顺的部分。

Q3成本和延迟怎么权衡？

多路召回与粗排精排的分层本身就是延迟与效果的权衡；他能讲清每一层为什么存在。

他的准备方法贯穿始终：把项目转成简历 bullet 和面试问答，用 STAR（背景–任务–动作–结果）讲清取舍，而不是堆技术名词。

CASE 01

Ethan

双非本科 · 211 硕士
准备 3 个月科大讯飞、美的、TME 相关大模型岗位机会

起点：没有竞赛、论文，也没有大厂实习。简历上真正能打的只有两条项目：企业知识库 RAG 和工作流 Agent。第一次改项目时，最大的误区是把「做过」写成「会了」。这样的描述能过关键词筛选，却经不起第二个问题。

面试实录 · 三轮追问
Q1没有论文，项目深度怎么证明？

他没有再回答「效果不错」，而是把坏样本拆成事实问答、跨章节、表格、无答案四类，再分别记录分块、Embedding、rerank 的变化。项目从一个 Demo 变成一套能复现、能比较、能解释失败的系统。

Q2工具调用失败怎么办？

回答不再是「加重试」：缺参数就追问，权限不足就拒绝，超时走异步重试，写操作必须二次确认，持续失败才转人工，并保留完整 trace。面试官真正想听的是边界和代价，而不是框架名。

Q3同一个项目，为什么能投不同公司？

项目事实不变，表达重点切换：偏算法的岗位讲召回和评测，偏应用的岗位讲工具调用与状态机，偏业务的岗位讲权限、回退和线上指标。

CASE 02

Liam

普通本科 · 信息管理
无大厂实习深圳 Agent 开发岗 Offer

起点：过去讲项目总围绕 chunk、Embedding、向量库转，一旦被问「为什么论文表格召回不到」，回答就只剩「换一个模型试试」。这次他先停掉功能堆叠，专门做坏样本。

面试实录 · 项目深挖近 20 分钟
Q1为什么论文表格就是召回不到？

他先查解析层：PDF 解析后表格是否还在、表头和数值有没有被切开，再查语义层：论文名、数据集名、指标缩写是纯向量检索的盲区，给专有名词补上 BM25，并用固定分块和语义分块做对照。

Q2Reviewer 输出 JSON 不合法怎么办？重跑整条流程吗？

不重跑整条 pipeline：先校验字段，能修就修，不能修只重跑当前节点，连续失败再回退或人工接管。

面试官顺着表格解析和局部重试继续问了近 20 分钟。他第一次没有乱，也没有靠背名词硬撑。

CASE 03

Ryan

双非背景 · 多年全栈
转 AI 方向入职儿童 AI 玩具团队

起点：转 AI 时最大的优势不是「写代码快」，而是知道一个功能要怎样接进真实产品。他在 Idea2Paper 中持续提交代码：知识图谱构建界面、后端流水线、跨平台前端与任务进度。

面试实录 · 开源项目深挖
Q1这个开源项目里你具体做了什么？

他能展示的不只是最终页面，还有提交记录、模块边界和踩过的坑——面试官可以顺着代码继续验证。

Q2到端侧产品，工程难点变成什么？

入职儿童 AI 玩具团队后，问题从网页功能转向 ASR、情绪识别、RAG、Function Call、多 Agent 与设备延迟：前端懂交互、后端懂链路，端侧还要懂延迟、失败和用户等待。

CASE 04

Mason

在职开发
2026 年 3–4 月集中补 Agent 工程多位面试官主动提起 Idea2Paper

起点：在职开发，项目包括 Agentic Search v2、知识图谱召回与去重、DeepResearch 和数据泄漏排查。

面试实录 · 面试官顺着开源项目往下问
Q1Idea2Paper 的 Agent 设计边界在哪里？Agent Team、Swarm、Harness 怎么选？

至少三位面试官主动提到这个项目并追问这些概念。他的答法：少讲「用了哪些框架」，多讲一次错误召回如何定位、一条搜索链路为什么这样拆。

Q2系统怎么持续优化？自动化做到哪一步？

讲清自动化做到哪一步必须停下来交给人。开源项目不是简历装饰，而是面试官可以顺着代码继续验证的入口。

后端经验让他更早意识到真正的产品问题：状态能不能持续、规则会不会被绕过、一次错误会不会污染后续剧情。

PATTERN

面试官最爱追问的五类问题

把 12 个案例的追问放在一起看，重复出现的就是面试官真正在筛的东西。训练营的项目与教程按这五类组织：每一类，你都有能展开讲的实物。

01

项目深度怎么证明

不是「效果不错」，而是坏样本分类、测试集、实验链。Lucas 整理 300 条测试集；Ethan 把坏样本拆成四类分别记录指标变化；Leo 每一步都要回答「数据为什么这样处理、和基线差在哪」。出现在 CASE 01 / 06 / 09
02

失败了怎么办

工具调用失败、输出不合法、生成错误污染后续，面试官要听校验、局部重试、回退、人工接管和完整 trace，而不是一句「加重试」。出现在 CASE 01 / 02 / 05
03

为什么这样设计

数据从哪来、召回怎么评估、成本和延迟怎么权衡。阿周的分层召回与 A/B 验证、Liam 的排查链（解析、分块、混合召回、rerank、评测），都是这个问题的答案库。出现在 CASE 00 / 02 / 08
04

边界与代价

权限不足就拒绝、高风险问题设拒答、自动化到哪一步交给人——面试官真正想听的是边界和代价，而不是框架名。出现在 CASE 01 / 04 / 07
05

同一个项目，换个岗位怎么讲

项目事实不变，表达重点切换：算法岗讲召回和评测，应用岗讲工具调用与状态机，业务岗讲权限、回退和线上指标。出现在 CASE 01 / 03

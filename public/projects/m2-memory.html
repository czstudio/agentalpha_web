01

MemSync 是什么

场景名「跨端个人记忆中台」不变，产品主体升级为 MemSync 的真实现状。

MemSync 是一个跑在用户自己电脑上的个人 Agent 与跨设备记忆系统。对外是一个产品，内含三条可独立叙述的能力：MemSync 产品本体（本地个人 Agent 与跨端记忆）、MemSync Code（产品里的代码智能体，负责技能学习与自我改进）、MemSync Train（训练与评测工厂）。自进化方向上，harness 内核吸收了 RRSI 选择核的机制（思想来源于 google-research/rrsi，工程实现自研）。

本机产品定位，如实说边界：推理、记忆、向量索引、训练数据、模型权重全部在本机，不调用任何云端模型 API；模型与记忆不出你的电脑。飞书消息与文档本就存放在飞书，经 lark-cli 读取到本机处理，手机端对话经飞书服务器中转，这一段不在本机之内。加密存储是服务端持有每用户密钥的静态加密，不是端到端加密；不写「零泄露」。

用户可以在一个网页端里与个人 Agent 对话、查看与纠正关于自己的记忆、在多台设备之间同步偏好、通过飞书接入数据，并随时导出或删除自己的数据。当前状态：注册登录、对话、记忆增删改与过期、多设备同步、导出导入、注销均已实现；飞书真实路径尚未真机联调，如实标注。

可迁移场景：陪伴产品长记忆、企业知识助手个性化、多设备偏好同步、Agent 记忆基础设施

03

记忆生命周期：撤回、压缩、溯源

记忆不是只进不出的日志：能撤回、能压缩、每句话能查出处。

级联撤回（MCP 记忆服务器，在建）：把 MemSync 记忆做成 MCP 服务器，Claude Code / Cursor / Codex 等客户端可读写；每条经 MCP 写入的记忆记录来源客户端，撤销客户端授权即级联撤回它写入的全部记忆。该机制按吸收扩充方案 v4 排期推进中，如实标「在建」，不冒充已完成。

压缩：多轮对话超过上下文预算时压缩旧轮次；压缩产物本身作为派生记忆进入溯源图，可查出处、可撤回。没有指针的压缩等于删除，这条规则写进实现。

grounding 逐句溯源：回答的每条可检验论断逐句回查记忆条目。对 41 条真实运行回答的审计：claim 级无支撑率 1.74%（2/115），run 级 5.56%（2/36），两个无支撑原因（归属错误 1、数值无法回溯 1）逐条入档（experiments/memsync_grounding/measurement.json）。

冲突消解与遗忘（m2 前代已验收）：向量钟 + 来源优先级 + LWW 合并多端写入，冲突消解评测 n=40 准确率 1.0 vs 朴素基线 0.4–0.8（配对 p≤0.0069，experiments/memcore-update-eval/results.json）；过期是可查询的否定（版本链），删除是不可查询的否定（墓碑）。

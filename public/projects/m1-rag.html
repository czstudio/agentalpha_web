它是什么、解决什么问题、做完效果如何。

一句话定位：我们不是在做一个问答机器人，而是在用 RAG 重塑知识的组织方式，让数据自己开口说话。

系统从底层数据采集、语义切分、向量索引、语义重排到答案生成全流程闭环、可追溯、可扩展。更重要的是它的出身——我们并非凭空设计，而是参考并提炼了曾为北美顶级金融独角兽交付的定制化 RAG 系统：那套系统支撑上万份财报、风控文件的实时问答与可审计访问。这次我们把那套企业级架构理念「轻量化」，做成一套通用的 RAG 实战模板，让任何团队都能以极低门槛复刻出自己的智能知识中枢。

对学习者，它是一条完整的动手链路。教程提供完整答案代码和一个纯 TODO 骨架——骨架搭完，系统就是你的。

实验证据

页面上的每个数字都能在你自己的电脑上跑出来。

0.900 → 0.991 怎么测出来的

召回：BM25 0.900 → 向量 0.991（220 题公开数据集，bootstrap 一千次重采样置信区间）；换对检索器 +9.1 个百分点，之后融合与再搜在小语料上已饱和——如实记录，不硬讲成四级递进。

排序质量：MRR@10 从 0.456 到 0.536。

归因：两路不一致的 24 题逐题核对，21 题由向量救回、1 题由词面救回、1 题双漏暴露天花板——催生了按需再搜。

多 Agent 产线另有对抗注入 10/10 拒绝、15 项事实对账全对的实测。完整记录见实验证据中枢。

求职怎么用

按 2026 年大厂在招岗位的真实要求逐条对标——考察已从「搭过 demo」升级为四条硬线：检索质量可评测、系统工程化、Agentic 化、与最新架构对话。这个项目覆盖前三条的全部地基，第四条在教程「最新进展」节逐篇讲。

对齐的真实岗位要求

RAG 全链路落地（字节·知识库后端）多路召回/重排/效果评测（美团·智能问答）幻觉治理与引用溯源评测体系设计（文基智能 JD 原词）Agentic 检索（阿里国际 JD 原词）

JD 里出现的新词（Agentic RAG、GraphRAG），你在这门课里有对应的动手章节或论文精讲，而不是只听过名词。

简历怎么写 · 三条可直接用的

将单路 BM25 检索改造为 BM25+向量双路 RRF 融合，在 MS MARCO 220 题封存评测集上 Recall@10 从 0.900 提升至 0.991；小语料下向量召回已饱和、融合未再提升（如实归档），全部数字经 bootstrap 1000 次重采样给出置信区间并做逐题分歧归因。

改动：单路→双路融合结果：+9.1pp边界：小语料饱和验证：CI+归因

实现编号级引用与两道拒答门控（检索空结果硬拒答前置 + 生成提示词软约束），知识库外问题 0 编造；代价是放弃对库外问题的覆盖率换取金融场景可审计性，用无据问题专项集验证拒答正确率。

改动：两道门控结果：0 编造边界：放弃覆盖率验证：专项集

为检索链增加按需再搜循环（模型自判证据充分性、改写查询、3 轮硬上限），实测平均 2.16 轮、65% 问题触发二搜；小语料上召回未获提升（0.986→0.986）如实入档，每轮查询与判定全量落盘可复查。

改动：再搜循环结果：2.16 轮边界：召回未提升验证：全量落盘
写法公式：我改了什么 + 量化结果（实测）+ 代价或边界 + 怎么验证的——四成分缺一个都会被面试官当成玩具项目。每条经历都对应一个你亲手跑出来的数字。

常见问题

零基础能做这个项目吗？

会 Python 基本语法就可以。第 1 章 15 分钟跑通第一个可运行 RAG；深度学习基础不是前置，教程里公式都有逐行的人话解释。

需要 GPU 吗？

学习主线（建库、检索、界面）一台普通笔记本就能跑；第 4 章的再搜实验用到了本地推理模型，教程给了云端按小时租用的替代方案和一键脚本。

需要调用付费大模型 API 吗？

问答演示需要一个对话模型 API（各家都有免费额度）；评测链路和夹具全部离线可跑，不花钱。

和网上开源的 RAG demo 有什么区别？

三点：有 220 题公开基准评测（绝大多数 demo 没有评测）；有 teacher/student 双版本（demo 只有能跑的代码，没有教学骨架）；有逐题归因的实验记录（数字可溯源到文件）。

做完了能达到面试水平吗？

面试深挖的五个高频问题（切块怎么选/为什么双路/数字怎么测/失败案例/怎么防幻觉）每一条在教程里都有专节，做完项目你就带着答案去面试。
